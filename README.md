# atelie-vareda

Site one-page estático (HTML + CSS + JS inline, fontes e imagens locais). Sem build.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `atelie-vareda`.
2. (Já feito) URLs de canonical, Open Graph, sitemap e llms.txt apontam para erik-akaishi.github.io.
3. Envie todos os arquivos desta pasta para a raiz do repositório (incluindo o `.nojekyll`).
4. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
5. O site fica em `https://SEU_USUARIO.github.io/atelie-vareda/`.
6. Rode o Lighthouse na URL pública.

Observação: `robots.txt` e `sitemap.xml` só têm efeito na raiz de um domínio; em github.io/repositório servem de documentação até existir domínio próprio.
